# 音频文件目录

将真实音频文件放置在此目录中，文件名需与下方对应。

## 文件命名规范

| 声音 ID   | 文件名               | 说明       |
|-----------|---------------------|-----------|
| muyu      | muyu.mp3            | 木鱼       |
| yinching  | yinching.mp3        | 引磬       |
| dingxia   | dingxia.mp3         | 丁夏       |
| singing_bowl | singing_bowl.mp3  | 颂钵       |

## 音频要求

- 格式：MP3（推荐 128kbps 以上）
- 时长：3-10 秒（法器鸣响的自然长度）
- 声音：真实录制为佳，确保无杂音、无爆音
- 体积：单文件建议不超过 500KB

## 优先级

当 audio/ 目录中存在对应的真实音频文件时，系统会自动优先播放真实音频；
若文件不存在或加载失败，会自动回退到 Web Audio 合成音效。

## 替换方法

1. 准备好 MP3 文件
2. 按上述命名规范重命名
3. 放入本目录即可生效
