# 禅心 · 冥想日记

一款面向禅修者的冥想记录与计时工具，以佛教禅修传统为根基，融合现代极简设计美学，帮助修行者建立持续、有觉知的冥想习惯。

## 项目简介

「禅心」取自禅宗「即心即佛」之意。本应用不追求花哨的功能堆叠，而是围绕禅修者的核心需求——**静坐、觉知、回观**——构建一个安静、沉浸的数字修行空间。

用户可以自由选择冥想类型与时长，配合传统法器音声作为结束提示，在冥想结束后记录心情与感悟。所有数据存储在本地浏览器中，无需注册、无需联网、无任何数据上传。

## 功能概览

### 冥想计时

- **20 种冥想类型**：涵盖南传上座部禅法（观呼吸、慈心禅、佛随念、身至念、死随念、毗婆舍那、行禅、安那般那念、四念处）、大乘禅法（坐禅、公案参究、持咒、观想）、四无量心修习（慈、悲、喜、舍）以及太极、气功、瑜伽休息术等身心法门
- **灵活的时长设置**：5 / 10 / 20 / 30 / 45 / 60 分钟快捷选择，或自定义 5–120 分钟（步长 5 分钟）
- **传统法器提示音**：木鱼、引磬、丁夏、颂钵四种结束提示音，由 Web Audio API 实时合成，无需加载音频文件
- **沉浸式计时**：全屏沉浸界面，隐藏导航栏与标签栏，搭配呼吸引导光晕，减少视觉干扰

### 心情与感悟

- **六种心情状态**：平静、喜悦、忧伤、焦虑、疲倦、烦躁
- **冥想感悟**：自由文本记录，支持分享为卡片图片

### 首页概览

- **本周冥想**：七日圆点可视化，一眼掌握本周修行节奏
- **心情散点图**：近 30 天心情分布，圆点大小反映频率，带碰撞物理动效

### 日记

- **按月分页**：左右切换月份，默认定位当月
- **类型筛选**：基于当前月份实际冥想类型动态生成筛选标签
- **时间线展示**：按日期分组展示冥想记录

### 个人中心

- **数据概况**：连续天数（金色稻穗装饰）、总天数、总分钟、总次数
- **冥想日历**：月历视图标记冥想日，点击日期查看当日详情
- **设置管理**：自由开关 20 种冥想类型（至少保留 4 项）

## 技术架构

### 整体方案

纯前端单页应用，HTML + CSS + JavaScript 多文件架构，零构建依赖，浏览器直接运行。数据持久化依赖 `localStorage`，冥想计时状态通过 `sessionStorage` 在页面间传递。

### 目录结构

```
meditation-diary/
├── index.html              # 首页
├── meditate.html           # 冥想设置页
├── timer.html              # 沉浸式计时页
├── reflection.html         # 冥想复盘页
├── journal.html            # 冥想日记页
├── profile.html            # 个人中心页
├── settings.html           # 设置页
├── css/
│   └── style.css           # 全局样式（约 1900 行）
├── js/
│   ├── constants.js         # 纯数据常量（类型、心情、音声、呼吸相位）
│   ├── store.js             # 数据层：localStorage 读写、设置管理、统计计算
│   ├── session.js           # sessionStorage 桥接：冥想状态跨页面传递
│   ├── utils.js             # 通用工具函数
│   ├── audio.js             # Web Audio API 音声合成（木鱼/引磬/丁夏/颂钵）
│   ├── home.js              # 首页：问候语、本周圆点、心情散点图（含碰撞物理）
│   ├── meditate.js          # 冥想设置：类型选择、时长设置、音声试听、底部弹窗
│   ├── timer.js             # 计时器：倒计时、呼吸引导、暂停/继续
│   ├── reflection.js        # 复盘：心情记录、感悟书写、保存/放弃
│   ├── journal.js           # 日记：按月分页、类型筛选、记录列表
│   ├── profile.js           # 个人中心：统计、日历、日期详情
│   └── settings.js          # 设置：类型开关管理
└── README.md
```

### 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 数据存储 | `localStorage` | 纯前端，无需服务端，用户数据完全本地化 |
| 计时状态传递 | `sessionStorage` | 跨页面（设置→计时→复盘）传递冥想参数，会话结束自动清除 |
| 音声合成 | Web Audio API | 实时合成法器音色，零音频文件加载，包体极小 |
| 心情散点动效 | `requestAnimationFrame` | 碰撞物理模拟，初始网格排列 + 80 次分离迭代 + 弹性碰撞 |
| 沉浸式页面 | 独立 HTML + 隐藏导航 | 计时页和复盘页移除导航栏/标签栏，营造无干扰环境 |
| 垂直居中 | `margin: auto` 伪元素 | 解决 `justify-content: center` 在内容溢出时将底部推出视口的问题 |
| 脚本加载顺序 | `constants.js` → `store.js` | `store.js` 依赖 `ALL_TYPES`（定义于 `constants.js`），必须先加载 |

### 设计规范

- **配色**：深色主题（`#1a1a18` 底色），金色强调（`#c9a96e`），鼠尾草绿辅助（`#8fa886`）
- **字体**：Noto Serif SC（中文衬线）+ EB Garamond（西文衬线）
- **布局**：最大宽度 480px 居中，适配移动端优先
- **圆角体系**：8px / 12px / 20px / 28px 四级圆角
- **动效**：统一 0.3s ease 过渡，呼吸光晕 8s 循环，脉冲环 3s 循环

## 使用方式

直接用浏览器打开 `index.html` 即可运行，无需安装任何依赖或启动本地服务器。

推荐使用 Chrome / Safari / Edge 最新版，移动端可在微信内置浏览器中正常使用。

## 设计哲学

> 诸行无常，是生灭法。

冥想不是要获得什么，而是学会放下。「禅心」的设计遵循同样的原则：界面做减法，交互做留白，让工具隐退，让觉知浮现。每一次呼吸提示、每一声法器音、每一粒稻穗装饰，都是对「正念」这一核心价值的呼应——不是帮助你做更多，而是帮助你「在」更多。
